# engishiki-quantity-conversion
延喜式巻24主計式上の物品貢納量を丁数へ換算し、国別集計等を行うための処理コードです。
入力XMLデータおよび出力例も併せて収録しています。

ファイル
・換算処理コード.py
・engishiki_v24.xml
・engishiki_taxonomy_standoff_master.xml
・結果（国別集計）.txt
・結果（rule確認）.txt
・結果（ログ）.txt

入力ファイル　実行時に以下のファイルのパスを入力してください。
・engishiki_v24.xml
・engishiki_taxonomy_standoff_master.xml
・出力先フォルダ

出力ファイル　指定した保存先フォルダに以下のファイルが出力されます。
・結果（国別集計）.txt
・結果（rule確認）.txt
・結果（ログ）.txt

本コードは研究用途です。
